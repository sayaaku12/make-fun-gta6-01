SOLMAR BAY — an original open-world crime game in the spirit of GTA 6: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police across a 1–5 star wanted level, and play a 6-mission story as Ria "Vex" Marlowe. Traffic, pedestrians, combat, taxi fares, hidden packages, stunt jumps, a HUD with minimap, and a save system. Keyboard + mouse, offline in a desktop browser, original art and synthesized sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
